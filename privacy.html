Política de privacidad

Tele salón es una app de uso personal instalada en una sola tele.

  • Pide acceso a YouTube para leer tu inicio y saber a qué canales estás suscrito.
  • El permiso y esos datos se guardan solo en la propia tele. No se envían a ningún servidor propio ni se comparten con nadie.
  • La app no publica, modifica ni borra nada de tu cuenta.
  • Puedes retirar el permiso cuando quieras en myaccount.google.com/permissions.

El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
